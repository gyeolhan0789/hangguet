# 면접관 표현 모듈: 개요

> 질문을 면접관 음성으로 출력하고, 경청·생각·발화 상태와 반응을 면접관(3D 또는 2D 그림)으로 표현한다.

결정 사항: [decisions.md](decisions.md) · 아키텍처: [architecture.md](architecture.md) · 검증 결과: [verification.md](verification.md)

## 1. 모듈 기능

| 기능 | 내용 | 예시 |
|---|---|---|
| ① 음성 합성 (TTS) | 질문 Text를 면접관 음성으로 변환한다. TTS 호출은 BE 요청으로 AI 파트에서 수행하고, 본 모듈은 TTS 선정·페르소나별 음성 스타일·음성 재생을 담당한다 | "장애가 발생했던 경험을 말씀해 주세요." → 음성 |
| ② 립싱크 | 음성 재생에 맞춰 입 모양을 동기화한다 | 음량에 비례해 입을 열고, 재생 종료 시 닫는다 |
| ③ 면접관 렌더링 | 면접관(3D 모델 또는 2D 그림)을 표시하고, 전달받은 상태·표정·제스처를 동작으로 표현한다 | `listening` 수신 → 사용자 응시, 짧은 끄덕임 |

**범위 제외**: 반응 판단(반응 로직 모듈), 질문 생성·TTS 호출(면접 AI 모듈), 음성 파일 저장·URL 발급·반응 이벤트 전달(BE), 사용자 비언어 분석(피드백 모듈), 화면 흐름·배경 이미지(UI)

## 2. 면접관 상태

| 상태 | 전환 시점 | 표현 |
|---|---|---|
| idle | 대기 | 호흡, 눈 깜빡임 |
| speaking | 질문 도착 (BE) | 립싱크, 정면 응시 |
| listening | 질문 음성 재생 종료 또는 글 표시 시간 종료 (자동) | 사용자 응시, 간헐적 끄덕임, 입 닫힘 |
| thinking | "답변 완료" 버튼 (사용자) | 고개 살짝 기울임 |

- 질문 표시는 음성·글·둘 다 3가지 모드이고, 글 모드 표시 시간은 `max(2초, 글자 수 ÷ 7초)`다.
- "답변 완료" 이후 도착한 반응 이벤트는 버린다.

## 3. 페르소나

| | 악마 면접관 | 개발자 커피챗 | 장난꾸러기 악마 |
|---|---|---|---|
| 렌더러 | 2D 점 찍어 휘기 (10/14 변경, 이전 3D). 실사 그림 사용 여부는 협의 후 확정 | 2D 점 찍어 휘기, 반실사 그림 (10/14 변경, 이전 3D) | 2D 점 찍어 휘기, 반실사 그림 |
| 외형 | 40대 남성, 검은 정장·흰 셔츠 | 30대 남성, 체크 셔츠 | 사람 모습의 악마(작은 뿔·붉은 눈), 동그란 안경, 남색 정장·빨간 넥타이 |
| 질문 스타일 | 짧고 딱딱한 압박형 | 대화형 | 장난스럽게 약 올리며 파고드는 꼬리질문형 |

"악마"는 외형이 아니라 질문 스타일을 뜻한다(악마 면접관). 표정 배율·목소리 등 상세 값은 [verification.md](verification.md) 5.2절.

## 4. 준수 사항

- 본 모듈은 반응을 판단하지 않으며, 전달받은 상태·표정·제스처만 표현한다. 어떤 표정(부정 표정 포함)을 언제 보일지는 반응 로직 모듈이 결정한다.
- 사용자 카메라 영상은 면접관 표현에 사용하지 않는다.
- 렌더링 실패(WebGL 미지원 등) 시 정지 화면과 음성으로, TTS 실패·음성 로드 실패 시 질문 Text로 면접을 계속 진행한다.
- 면접관 모델과 TTS 음성의 라이선스를 확인하고, 합성 캐릭터·합성 음성임을 사용자에게 고지한다.

## 5. 타 모듈 연동

| 연동 항목 | 연동 대상 | 형식 |
|---|---|---|
| 질문 요청 → 질문 Text·음성 URL | BE | FE가 BE에 질문 요청, BE가 질문 Text와 읽기용 Presigned URL 전달 (협의 필요) |
| 질문 Text → TTS 호출 | 면접 AI 모듈 (AI) | BE 요청으로 질문 JSON의 `text`를 TTS로 변환, 업로드용 Presigned URL로 Storage에 업로드. FE와 직접 연동하지 않음 |
| 반응 이벤트 → 면접관 | 반응 로직 모듈 (판단) → BE (WebSocket) | 반응 이벤트 ([architecture.md](architecture.md) 2장). 쉴 때 끄덕임만 FE 안에서 발생 |
| 면접관 화면 배치·배경 이미지 | UI (FE) | 얼굴을 화면 위쪽 1/3에 두는 상반신 구도, 배경 이미지 위에 투명하게 겹침 |
