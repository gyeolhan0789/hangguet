# 면접관 표현 모듈: 개요

> 질문을 면접관 음성으로 출력하고, 경청·생각·발화 상태를 3D 면접관으로 표현한다.

결정 사항: [decisions.md](decisions.md) · 아키텍처: [architecture.md](architecture.md)

## 1. 모듈 기능

| 기능 | 내용 | 예시 |
|---|---|---|
| ① 음성 합성 (TTS) | 질문 Text를 면접관 음성으로 변환한다. TTS 호출은 BE 요청으로 AI 파트에서 수행하고, 본 모듈은 TTS 선정·음성 스타일·음성 재생을 담당한다 | "장애가 발생했던 경험을 말씀해 주세요." → 음성 |
| ② 립싱크 | 음성 재생에 맞춰 입 모양을 동기화한다 | 음량에 비례해 입을 열고, 재생 종료 시 닫는다 |
| ③ 면접관 렌더링 | 3D 면접관을 표시하고, 반응 로직 모듈이 전달한 상태·표정·제스처를 동작으로 표현한다 | `listening` 수신 → 사용자 응시, 짧은 끄덕임 |

**범위 제외**: 반응 시점 판단(반응 로직 모듈), 질문 생성·TTS 호출(면접 AI 모듈), 음성 파일 저장·URL 발급(BE), 사용자 비언어 분석(피드백 모듈), 화면 흐름(UI)

## 2. 면접관 상태

| 상태 | 전환 시점 | 표현 |
|---|---|---|
| idle | 대기 | 호흡, 눈 깜빡임 |
| listening | 사용자 발화 중 | 사용자 응시, 간헐적 끄덕임, 입 닫힘 |
| thinking | 사용자 발화 종료 후 | 시선 이동, 고개 기울임 |
| speaking | 질문 음성 재생 중 | 립싱크, 정면 응시 |

상태 전환 시점은 반응 로직 모듈이 결정하며, 본 모듈은 전달받은 상태를 표현한다.

## 3. 준수 사항

- 답변 평가 결과와 사용자 카메라 영상은 면접관 표현에 사용하지 않는다. 평가 결과에 따른 부정적 표정은 출력하지 않는다.
- 3D 렌더링 실패 시 정지 화면과 음성으로, TTS 실패·음성 로드 실패 시 질문 Text로 면접을 계속 진행한다.
- 면접관 모델과 TTS 음성의 라이선스를 확인하고, 합성 캐릭터·합성 음성임을 사용자에게 고지한다.

## 4. 타 모듈 연동

| 연동 항목 | 연동 대상 | 형식 |
|---|---|---|
| 질문 요청 → 질문 Text·음성 URL | BE | FE가 BE에 질문 요청, BE가 질문 Text와 읽기용 Presigned URL 전달 (협의 필요) |
| 질문 Text → TTS 호출 | 면접 AI 모듈 (AI) | BE 요청으로 질문 JSON의 `text`를 GMS TTS로 변환, 업로드용 Presigned URL로 Storage에 업로드. FE와 직접 연동하지 않음 |
| 상태·표정·제스처 → 면접관 | 반응 로직 모듈 (FE) | 반응 이벤트 ([architecture.md](architecture.md) 2장) |
| 면접관 화면 배치 | UI (FE) | 협의 필요 |
