**배운 것 / 정리**
- 렌더러 비교: 자체 컨트롤러가 120fps·번들 +7kB로 TalkingHead(최대 72fps·+226kB)보다 가볍고, TalkingHead의 자동 대기 동작·표정은 우리 동작 층 구조와 충돌
- 립싱크: HeadAudio는 영어 학습 모델이라 한국어 "아"를 한 번도 `viseme_aa`로 분류하지 못함 → MVP는 음량 기반, HeadAudio는 2차
- 2D 그림 면접관: 새 내용(감은 눈·벌린 입)은 코드로 지어낼 수 없고 그린 그림이 필요. 눈·입 그림은 기본 그림과 실제로 달라지는 영역만 남겨야 표정 그림 위에 겹쳐도 티가 나지 않음
- 시험(spike) 결과물 관리: 결과와 근거는 문서로 남기고, 시험 코드는 핵심만 발췌하며 제품 코드로 복사하지 않음
- 라이선스: MakeHuman 에셋 CC0, TalkingHead MIT, Windows 기본 음성은 배포 불가. MetaHuman은 다른 엔진 사용이 허용됐지만 AI 학습·개선에는 사용 불가

**막힌 것 & 해결**
| 문제 | 원인 | 해결 |
|---|---|---|
| 도형 아바타로 표정 변화가 보이지 않음 | 입이 가로선 하나라 표정 표현 불가 | 실제 GLB 모델 연결 |
| 입을 벌리면 혀가 튀어나옴 | 모델 빌드 시 혀 위치 미보정 | 빌드 스크립트에서 혀 보정, 립싱크 상한 0.55 |
| 2D 표정 위에 말하는 입을 겹치면 입이 두 겹으로 보임 | 타원 마스크 밖에 표정 그림의 입꼬리가 남음 | 그림끼리 달라지는 영역만 남기는 부위 조각 방식으로 변경 |
| 실제 모델에서 미소·찌푸림이 거의 안 보임 | 새 모델은 같은 수치라도 표정이 약하게 나옴 | 화면을 보며 표정 수치·페르소나 배율 조정, 전후 비교 기록 |
| Blender가 에셋을 읽지 못함 | Windows 경로 260자 제한 | 작업 폴더를 짧은 드라이브 문자(`subst`)에 연결 |
| 기획 문서의 TTS 호출 구조가 협업 규칙과 어긋남 | FE가 GMS를 직접 호출·Credential 보유 | `CONTRIBUTING.md` 6.1·7장에 맞게 BE·AI 경유 구조로 수정 (S15P31A301-47) |
| 반응 로직 계획과 기획 문서의 부정 표정 금지 문구 충돌 | 반응 판단 기준을 표현 모듈 문서에 적어 둠 | 반응 판단은 반응 로직 모듈, 표현 모듈은 받은 대로 표현하는 것으로 범위 정정 |
