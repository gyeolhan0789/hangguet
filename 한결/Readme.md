### 📅 2026-10-14 (수)

**오늘 한 것**

- React(Vite), Node.js(Express), Simli JS SDK로 2D 실사형 AI 면접관 PoC 구현
- 한국어 MP3/WAV를 16kHz PCM16으로 변환해 립싱크 테스트
- IDLE·NOD·TILT·FROWN 반응 영상 전환, 크로스페이드 및 IDLE 복귀 구현
- GMS TTS 연동 코드 작성 및 3D VRM 데모와 품질 비교

**배운 것 / 정리**

- 음성과 입의 타이밍은 대체로 일치했지만, 입 모양이 단조로워 자연스러움이 부족했다.
- 이번 테스트에서는 artalk가 fasttalk보다 소폭 우세했다.
- 반응 영상 전환은 동작했으나, 실제 인물 영상 제작과 AI 이벤트 연동은 아직 필요하다.
- v1은 3D VRM 방식을 우선 적용하고, Simli는 Trinity 품질 검증 후 재검토할 예정이다.

**막힌 것 & 해결**

| 문제 | 원인·확인 내용 | 대응 |
| --- | --- | --- |
| 립싱크·실시간 반응의 자연스러움 부족 | 사용한 API에서 입 크기·표정·고개를 직접 제어하지 못함 | v1은 3D VRM 우선 검토 |
| GMS TTS 실사용 미검증 | API 키 미발급 | 한국어 음성 파일로 우선 검증, 키 발급 후 연동 테스트 |
| 실제 인물 반응 영상 미구현 | 현재 테스트용 이미지 기반 영상 사용 | 실제 영상 제작 및 AI 이벤트 연동은 후속 검증 |

### 📅 2026-10-12 (월)

**오늘 한 것**
- 2D·3D·실사형 아바타 구현 방식 비교 및 공식 문서 조사
- TalkingHead·three-vrm, 한국어 립싱크, 반응 이벤트 연동 방식 정리
- MVP 범위, 버전별 로드맵, 모델 호환·성능·라이선스 검증 항목 작성

**배운 것 / 정리**
- TalkingHead는 표정·시선·제스처·음성 연동을 제공하지만 모델 규격 검증이 필요하다.
- Azure는 한국어 Viseme ID를 지원하며, 모델 입 모양으로의 매핑이 필요하다.
- 립싱크는 실제 음성 재생 시간을 기준으로 맞추고, 중단 시 음성·입·동작 큐를 함께 취소해야 한다.

**막힌 것 & 해결**
| 문제 | 원인 | 해결 |
|---|---|---|
| 모델·TTS·립싱크 조합 미확정 | 후보별 호환성과 한국어 품질 실측 필요 | 공식 예제 모델로 v0 검증 후 팀과 구현 방식 합의 예정 |

**내일 할 것**
- [ ] 팀 노트북에서 TalkingHead 예제의 로딩·프레임·모델 호환 확인
- [ ] 기존 VRM 기획과 TalkingHead 제안 비교·합의
- [ ] 한국어 TTS와 HeadAudio·Azure Viseme 품질 비교
- [ ] 반응 AI 담당과 이벤트 형식·취소·만료 정책 협의
