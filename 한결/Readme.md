### 📅 2026-10-12 (월)

**오늘 한 것**
- 2D·3D·실사형 아바타 구현 방식 비교 및 공식 문서 조사
- TalkingHead·three-vrm, 한국어 립싱크, 반응 이벤트 연동 방식 정리
- MVP 범위, 버전별 로드맵, 모델 호환·성능·라이선스 검증 항목 작성

**배운 것 / 정리**
- TalkingHead는 표정·시선·제스처·음성 연동을 제공하지만 모델 규격 검증이 필요하다.
- Azure는 한국어 Viseme ID를 지원하며, 모델 입 모양으로의 매핑이 필요하다.
- 립싱크는 실제 음성 재생 시간을 기준으로 맞추고, 중단 시 음성·입·동작 큐를 함께 취소해야 한다.

**막힌 것 & 해결**
| 문제 | 원인 | 해결 |
|---|---|---|
| 모델·TTS·립싱크 조합 미확정 | 후보별 호환성과 한국어 품질 실측 필요 | 공식 예제 모델로 v0 검증 후 팀과 구현 방식 합의 예정 |
