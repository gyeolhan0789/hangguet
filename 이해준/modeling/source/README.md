원본을 변경하지 않고 보관한다. 파일 내 허용 설정은 modification=allowModificationRedistribution, commercialUsage=corporation, allowRedistribution=true, avatarPermission=everyone, creditNotation=unnecessary이다. 원본 권리자와 이용 조건을 유지한다.

상위 폴더의 character_base.blend는 새 장면에 이 모델을 불러온 작업 시작 파일이다. Body, Face, Hair, 리깅 및 얼굴 모프 57개가 포함되어 있다.
