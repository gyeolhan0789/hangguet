| 구분 | MVP 후보 |

| 언어 신호 | 초당 음절 수, 긴 쉼, 군말 (STT 결과로 계산) + 말투 (Kiwi 형태소 분석) |

| 묶기 | 모든 신호를 같은 시간축의 이벤트로 만들고, 문장 단위 장면으로 모아 LLM으로 피드백 문장 생성 |
