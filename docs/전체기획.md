# AI 모의면접 서비스 전체 기획

> 이 회사 면접관 눈에 내 답이 어떻게 보이는지 알려주는 면접 연습

## 1. 왜 만드나

기존 모의면접은 연습은 되지만, 잘한 건지 알기 어렵다.

| 기존 문제 | 우리가 하는 것 |
|---|---|
| 누구에게나 나올 법한 일반 질문 | 회사 자료를 근거로 한 맞춤 질문 |
| 점수만 주고 회사에 맞는 답인지는 모름 | 내 답이 이 회사에 맞는지 근거와 함께 평가 |
| 시선 72점 같은 점수 위주 피드백 | 어느 순간, 왜 그랬는지 장면 단위 피드백 |
| 말하는 동안 면접관 반응이 없음 | 듣는 중에 반응하는 면접관 |

## 2. 사용 흐름

공고 입력 → 공고 분석(회사 정보 · 예상 질문) → 면접 준비 → 모의면접 → 리포트

## 3. 개발 원칙

- 처음부터 크게 만들지 않는다. 버전을 나눠 단계적으로 고도화한다.
- 버전 구분과 방법론은 각 파트 담당이 정한다.

## 4. 역할 분담

| 파트 | 담당 | 범위 |
|---|---|---|
| 면접 AI: 질문 생성 · 답변 평가 | 다빈 | 회사 자료 수집·요약, 회사 맞춤 질문 생성, 답변의 회사 적합도 채점 방법을 알아보고 설계한다. |
| 피드백: 언어 · 비언어 분석 | 해준 | 말투·속도·군말 같은 언어 신호와 시선·표정 같은 비언어 신호를 분석하는 방법, 그리고 이를 답변 내용과 묶어 피드백하는 방법을 알아보고 설계한다. |
| 면접관 반응: 반응 로직 | 지웅 | 사용자가 말하는 동안 면접관이 언제, 어떤 반응(끄덕임, 갸웃, 끼어들기 등)을 할지 실시간으로 판단하는 방법을 알아보고 설계한다. |
| 면접관 외형: 아바타 표현 | 연수, 결 | 면접관을 화면에 어떤 형태로 보여 줄지, 그리고 판단된 반응과 음성을 표정·동작·입 모양으로 표현하는 방법을 알아보고 설계한다. |
| 화면: 프로토타입 · UI | 정복 | 공고 입력부터 면접, 리포트까지의 화면 흐름과, 각 파트 기능을 화면에 연결하는 방법을 알아보고 설계한다. |

각 파트 세부 문서는 레포의 개인 폴더에 정리한다. (예: [박다빈/interview-ai](../박다빈/interview-ai/README.md))

## 5. 파트끼리 맞춰야 할 것

| 주고받는 것 | 관련 파트 |
|---|---|
| 질문 → 면접 화면 | 면접 AI → 화면 |
| 답변 텍스트·음성 | 화면 → 면접 AI, 피드백, 반응 로직 |
| 반응 이벤트 (끄덕임 등) | 반응 로직 → 아바타 |
| 채점 결과 · 장면 피드백 → 리포트 | 면접 AI, 피드백 → 화면 |
