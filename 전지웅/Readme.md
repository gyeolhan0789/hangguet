### 📅 2026-10-12 (월)

**오늘 한 것**
- 실시간 음성인식(STT) 서비스 조사·비교 → 스트리밍 방식인 RTZR로 결정
- 면접관 반응에 쓸 Jev 조사 (공식 문서, 외부 측정 자료)
- 면접관 반응 구현 방안 문서 작성 (목소리 수집 → 글자 변환 → 문장 끝 판단 → Jev 판단 → 표정·끼어들기)

**배운 것 / 정리**
- **STT 방식**: Whisper처럼 녹음 파일을 보내는 방식은 답변이 끝나야 글자가 나옴. 답변 도중 반응하려면 말하는 동안 글자를 계속 주는 스트리밍 방식이 필요
- **문장 끝 판단**: 한국어는 문장 끝에서 뜻이 정해지므로 반응은 문장이 끝난 뒤에 냄. 말끝("～습니다", "～는데"), 문장부호, 0.3초 멈춤을 함께 보고 판단
- **Jev**: 글을 읽고 보기 중에서 고르거나 점수를 매기며, 얼마나 확신하는지도 알려줌. 응답은 약 0.3초. 표정은 Jev가 아니라 우리 코드에서 결정
- **반응 구분**: 듣는 동안의 전체 태도 / 잠깐 쉴 때의 맞장구 / 문장 끝의 반응 / 끼어들기

**막힌 것 & 해결**
| 문제 | 원인 | 해결 |
|---|---|---|
| 처음 세운 반응 계획이 Jev 특성과 맞지 않음 | Jev의 성능·속도·사용법을 확인하지 않고 계획부터 세움 | 공식 문서와 외부 측정 자료로 다시 조사해 계획 수정 |
| STT 비용이 실제와 다르게 계산됨 | 스트리밍인데 답변 단위 파일 전송처럼 계산 | 면접 시간(회당 30분) 기준으로 다시 계산 |

- [ ] RTZR 스트리밍 실제 지연 시간 측정
- [ ] 면접 답변으로 Jev 한국어 판단 정확도 테스트
