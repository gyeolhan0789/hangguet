# 내 담당: 정해야 할 것

[← 내 담당 문서로 돌아가기](overview.md)

## MVP 기준

> 회사 1곳이라도 **질문 → 답변 → 채점**이 끝까지 돌아가게 만든다. 나머지는 나중에 넓힌다.

**MVP 완료 기준**: 회사 10곳 중 하나를 고르면 질문 5개가 나오고, 텍스트로 답하면 채점 결과와 피드백이 나온다.

## ① 회사 자료 모으기

| # | 정할 것 | MVP | 나중에 |
|---|---|---|---|
| ①-1 | 어떤 회사부터 할지 | **10곳** (팀원들이 실제 지원하려는 회사 위주) | 100곳 → 전체 상장사 |
| ①-2 | 공시가 없는 회사 처리 | **지원 안 함** (상장사만) | 뉴스·채용공고만으로 카드 생성 |
| ①-3 | 요약 카드에 넣을 항목 | **인재상 + 사업 방향** 2개 | 최근 이슈, 직무 역량 추가 |
| ①-4 | 카드 갱신 주기 | **한 번 만들고 끝** (수동 실행) | Airflow로 주 단위 자동 갱신 |

- 카드 = 회사 하나를 요약한 정리표. 항목 = 그 표의 칸(인재상, 사업 방향 등). 모든 칸에 출처를 붙인다.
- MVP는 Python 스크립트로 10곳만 처리한다. Spark·Kafka 분산처리는 MVP가 돌아간 뒤 옮긴다.

## ② 질문 만들기

| # | 정할 것 | MVP | 나중에 |
|---|---|---|---|
| ②-1 | 면접 한 번에 질문 몇 개 | **5개** | 6~8개 |
| ②-2 | 질문 유형 비율 | **고정**: 경험 2, 회사 2, 인성 1 | 직무·회사별로 조정 |
| ②-3 | 꼬리질문 내는 시점 | **없음** | 답이 부족할 때만 1개 |
| ②-4 | 이력서가 없을 때 | **이력서 안 받음** (공고 + 카드만) | 이력서 반영 |

## ③ 답변 채점하기

서비스가 하는 일: 답변을 회사 카드와 비교 → 4개 항목을 3단계로 판정 → 지적 1개 + 고쳐 말할 예시 1문장.

| # | 정할 것 | MVP | 나중에 |
|---|---|---|---|
| ③-1 | 평가 기준이 쓸 만한지 확인 | **가상 답변 10개**에 팀원이 정답(판정)을 붙인다. 3개는 프롬프트 퓨샷 예시로, 7개는 AI 채점 테스트용으로 따로 둔다 | 정답 세트 30~50개 |
| ③-2 | 질문마다 볼 항목 | **모든 질문에 4개 항목 다 적용** | 질문 유형별로 다르게 |
| ③-3 | 너무 짧은 답 처리 | **그대로 채점** | "더 말해 보세요" 처리 |
| ③-4 | 채점 검증을 누가 할지 | **팀원 3명**이 따로 채점하고, 엇갈린 항목만 기준 수정 | 현직자·취업 컨설턴트 |

- 퓨샷 예시와 테스트용 답변은 섞지 않는다. 프롬프트에 넣은 예시로 테스트하면 AI가 답을 이미 본 상태라 의미가 없다.
- 테스트 7개는 프롬프트를 고칠 때마다 다시 돌려서 "7개 중 몇 개 일치"로 확인한다.

## 먼저 할 순서

1. ③-1: 가상 답변 10개 만들고 팀원 3명이 채점
2. ①-3: 카드 항목 2개(인재상, 사업 방향)로 10곳 카드 만들기
3. ②-1: 카드로 질문 5개 생성해 보기

결정이 바뀌면 이 표를 고치고, [내 담당 문서](overview.md)의 해당 부분도 고친다.
